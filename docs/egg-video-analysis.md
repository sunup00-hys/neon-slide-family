## 1차 웹 게임에 반영
- 블록 형태의 3D 캐릭터, 긴 지역별 탐험로, 후방 추적 카메라와 모바일 조이스틱.
- 목초지·정글·눈·용암·심해·천공 6지역과 각 지역의 추격자.
- 근처의 알 집기, 운반 중 감속, 스태미나 달리기, 알 내려놓기·다시 집기, 안전지대 도착 시 획득.
- 기본알·거대알·지역별 희귀알·이벤트알·비밀알·조합알. 크기·변이가 생산량에 영향.
- 인벤토리, 여러 부화기, 실제 시간 기준 부화, 펫 농장 배치/회수, 농장 확장.
- 펫의 초당 수익, 최대 12시간 오프라인 수익, 코인 수령.
- 러닝머신 단계 강화와 훈련으로 이동 속도 증가. 한 번의 훈련은 최대 10분.
- 캐릭터 6종을 게임 내 코인으로 구입·장착.
- 3분 주기의 1분 이벤트와 한정 알, 정글 옆 비밀 수정 동굴, 보관 펫 3마리 조합.
- 기존 가족 사용자 연결. 알·펫·코인·훈련·캐릭터·탐험 위치는 서버 저장. 공통 별은 그대로 유지.

## 의도적으로 조정
- 원작의 수 시간 부화를 20초~10분으로 줄여 가족이 짧게 플레이해도 성장 가능.
- 원작의 수십억~수조 속도 표시는 웹 공간에 맞는 실제 이동 속도 수치로 조정.
- 이름과 캐릭터·펫 외형은 직접 제작한 테마로 구성.

## 이번 구현에 포함하지 않는 영상 요소
- 여러 사람이 동시에 뛰는 실시간 멀티플레이, 다른 플레이어의 알 약탈·거래.
- 레이스 전용 경기, 공동 이벤트 보스 전투, 실시간 채팅, 서버 이동.
- 현금 결제와 확률형 유료 상품.

이 요소들은 화면만 흉내 내어 동작하는 것처럼 표시하지 않는다. 서버 저장 검증 후 순차 확장할 수 있다.
