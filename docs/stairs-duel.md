# 실시간 계단 대결 v1

- 기존 계단게임의 `⚔ 실시간 대결` 버튼 또는 `stairs-preview.html?duel=1`로 입장.
- 계단게임에서 사용자를 선택한 동안 접속 표시. 상대는 일반 플레이 중에도 신청을 수신할 수 있다.
- 참가자는 서로 다른 가족 사용자여야 한다. 한 사용자에게 동시에 두 대결을 잡지 않는다.
- 신청 30초 유효. 수락 후 양쪽 이미지 준비가 끝나야 공통 서버 시각으로 4초 카운트다운.
- 같은 seed, 같은 난이도, 기존 v2 계단 배열. 목표 100층. 부활/엘리베이터/능력치 아이템 사용 없음.
- 두 카메라가 각자의 캐릭터를 따라 이동. 기존 고화질 캐릭터/펫/계단을 사용한다.
- WebRTC 비디오 전송 대신 DataChannel로 20Hz 상태 전송. 외부 STUN은 Google/Cloudflare 사용, TURN은 사용하지 않는다. P2P가 안 되는 망에서는 350ms 간격의 서버 동기화로 자동 연결한다. 실제 반영 지연은 망과 서버 응답 시간에 따라 달라진다.
- 참가자의 순차 입력과 입력 시각을 서버가 재생해 점수/추락/목표 달성을 검증한다. 중복 입력은 한 번만 적용한다.
- 100층 선착순. 한쪽 추락 시 다른 쪽 승리. 판정 수신 오차를 위해 1초 정산 기간. 둘 다 추락하면 높은 층수, 같은 층수면 무승부. 둘 다 100층은 검증된 도착 시각 비교(30ms 이내 무승부).
- 연결 종료 15초 유예. 최대 경기 시간 2분. 새로고침 시 마지막 서버 저장 입력과 미확인 입력 묶음을 복구한다.
- 공개 접속 식별자와 비공개 세션 식별자를 분리한다. 상대의 접속 목록으로 상대 세션을 조작할 수 없다.
- 전적은 D1의 대결 테이블에 저장하며, 기존 공통 별/개인 최고 기록/게임 인벤토리는 변경하지 않는다. 대기실은 최근 50경기 전적을 기준으로 승패와 최근 기록을 보여준다.

## 검증

- `tests/stairs-duel.test.mjs`: 별도 서비스 인스턴스 간 신청/수락, 공통 시작 시각, 경기 입력 재생, 미래 입력 거부, 중복 요청, 점수 조작 거부, 제3자 접근 거부, 공개 ID로 세션 접근 거부, 중복 대결 방지, 비공개 시그널 전달, 재접속 유예, 재시작 후 전적 보존, 공통 별 보존.
- 기존 계단/공통 지갑 테스트를 함께 실행.
- 운영 데이터와 분리한 로컬 D1 + 두 브라우저 접속으로 대기실, 신청/수락, 동일 카운트다운, 양쪽 캐릭터 렌더링, A의 3층이 B의 상대 화면에 표시되는 것, 경기 종료 및 재대결 요청을 확인.
- 검증 환경에서는 서버 중계가 사용됐다. 인터넷의 서로 다른 실제 휴대폰 두 대에서 P2P 연결 품질/지연은 별도 확인이 필요하다.
